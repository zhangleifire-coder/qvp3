# 设计稿：旧链（混合合成）页型模板库 + 自动扩充 + 模板管理

> 编写日期：2026-09-24 ｜ 状态：待用户过目（未开工）
> 背景：用户裁决评估「旧链+页型模板库扩充」——文字 100% 无错字（PIL+微软雅黑），
> 版式丰富度靠模板库补齐；并要求：以后用户随时拿参考图/效果图来，能**自动扩充**进模板库，配**模板库管理**。
> 关联：发版记录-v40（直出模式现状）、0922 参考产出标准、layouts_cn.txt 11 页型。

---

## 1. 目标与非目标

**目标**
1. 程序排版链的版式从「7 个写死的 if 分支」升级为「数据驱动的模板库」——模板=JSON spec，渲染器通用执行；
2. 预置 11 页型模板（对齐 layouts_cn.txt / 0922 参考案例），保留页型轮换；
3. **参考图自动扩充**：用户给任意效果图/参考图 → VL 分析版式结构 → 生成模板 spec 草稿 → 预览渲染 → 入库待启用；
4. **模板库管理**：启停/预览/编辑/来源标记（预置/提取/手工），复用风格库管理模式。

**非目标（本轮不做）**
- 不动直出链（IMAGE_COMPOSE_MODE 当前仍 false，模板库就绪后由用户决定何时切）；
- 不追求直出的手绘有机感（高光笔歪斜、胶带褶皱）——程序版绘到「几何近似」为止；
- 不做字体采购/多字重混排（继续微软雅黑粗/常规两档，最多加一档思源宋标题）。

## 2. 总体架构

```
模板库（DB：compose_templates，spec=JSON）           ←管理页（Admin 加 tab）启停/预览/编辑
   │
   ├─ 11 预置模板（seed，由 layouts_cn.txt 逐型转写）
   ├─ VL 提取模板（source=vl_extracted，用户参考图自动生成，默认 enabled=false）
   └─ 手工模板（manual，管理页 JSON 编辑器）
   │
模板选择器 template_select(题材, 页角色, 轮换规则, task_id)   ←替代 pick_layout
   │
通用渲染器 render_card(spec, PageSpec, 插画[], 主题色板)      ←重构 compose_page
   │   区域合成（photo zones × 文字区 × 装饰层）
   │
出图 → 现有质检链（VL 综合质检/跨页检查，文字项必然通过）
```

**关键设计决策：模板词汇表封闭。** VL 提取不是自由发挥——装饰/标题形式只能映射到渲染器已实现的
**元素绘制器（painter）词汇表**（竖条标题、居中大字、序号徽章、胶囊、虚线、荧光块、贴纸、
拍立得边、胶带、VS 徽章、横幅、深底金句、小图标…）。提取=「看图选词 + 量几何参数」，
新视觉形态识别不了就归 nearest-painter 或忽略——**渲染能力有界，风险有界**。

## 3. 模板 spec 格式（v1）

```json
{
  "template_id": "cover_photo_overlay_v1",
  "name": "封面·大图压结论",
  "page_role": "cover",                    // cover / content / ending（轮换规则用）
  "tags": ["对比", "穿搭", "通用"],          // 题材适配（选择器打分）
  "canvas": {"ratio": "3:4"},
  "photo_zones": [                          // 照片区：数量+几何+风格
    {"x": 0.0, "y": 0.0, "w": 1.0, "h": 0.60, "fit": "cover",
     "frame": "none", "radius": 0}
  ],
  "photo_style": "生活实拍",                 // 生插画提示词前缀（沿用 sub_prompts 机制）
  "text_zone": {
    "x": 0.0, "y": 0.60, "w": 1.0, "h": 0.40,
    "bg": "theme_light",                    // theme_light / theme_deep / scrim(渐变罩) / transparent
    "elements": [                           // 有序元素流，自上而下排
      {"type": "title", "style": "accent_bar", "size": 54},   // accent_bar/center/overlay_on_photo/highlight
      {"type": "section_title", "style": "number_badge"},
      {"type": "paragraph", "size": 30, "leading": 1.53},
      {"type": "points", "style": "col", "columns": 2}        // col/grid_caption/none
    ]
  },
  "decor": [                                // 装饰层（painter 词汇表）
    {"type": "sticker", "corner": "br", "w": 0.16},
    {"type": "banner_strip", "at": "text_top", "text_from": "section_title"}
  ],
  "palette_rule": "theme_light",            // 色板规则（extract_palette 扩展）
  "source": "seed_11",                      // seed_11 / vl_extracted / manual
  "version": 1
}
```

校验规则（入库前）：坐标归一化且 photo_zones+text_zone 不越界重叠；字号 28-64；
元素流合法组合（overlay_on_photo 仅 cover）；深底页全套限 1 页（轮换器保证）。

## 4. 11 页型 → 程序绘制方案对照

| # | 页型（layouts_cn） | 程序绘制方案 | photo_zones | 文字区 | 装饰（painter） | 现有基础 |
|---|---|---|---|---|---|---|
| 0 | 封面页·情境结论钩子 | 上 60% 大图全幅+图上压字，下部浅底文字区 | 1 张 full 0.60 | title=overlay_on_photo（图区底部暗带白字大结论）+ 下区 accent_bar 主标题 + paragraph | 贴纸（角标） | overlay+ref 拼装，两分支已有 |
| 1 | 内容页·场景型 | 标准骨架：上 60% 图 + 下 40% 浅底 | 1 张 full 0.60 | accent_bar 标题 + number_badge 小节标题 + paragraph | 一枚圆角贴纸/小图标 | **ref 分支即此型**，微调即可 |
| 2 | 内容页·特写型 | 上 70% 特写图 + 下 30% 文字条 | 1 张 full 0.70 | accent_bar 标题 + paragraph（无小节标题） | 无（保持素净） | ref 改比例参数 |
| 3 | 内容页·对比型 | 左右双图并置 + 中央 VS 徽章 | 2 张 side-by-side 0.50 | 标题 + paragraph + banner_strip（对比结论短句，主题色底白字） | vs_badge + banner_strip | **vs_split 已有**，加 banner |
| 4 | 内容页·多图拼贴型 | 2×2 四宫格 / 三联横排 / 一大两小 | 3-6 张 grid（_grid_plan） | accent_bar 标题 + paragraph | 拍立得白边 + 胶带贴角（grid 单元级） | _paste_grid 已有，加边框装饰 |
| 5 | 内容页·步骤型 | 上 60% 步骤图（可 2 张连续动作） | 1-2 张 | number_badge 强化为大序号（1/2/3 步骤感）+ paragraph | 步骤序号大圆点 + 虚线连接 | ref+col 要点已有，序号放大 |
| 6 | 清单页 | 上 55% 多物品俯拍 | 1 张 full 0.55 | 标题 + paragraph 分 2-3 段 | 虚线段间分隔 + 荧光高亮块（关键词条，文字区局部底色块） | _draw_dashes 已有，加 highlight |
| 7 | 贴士页 | 上 50% 图 + 下部圆角贴士框 | 1 张 full 0.50 | 框外页标题 + 框内：框标题(小图标)+paragraph；框=圆角描边+浅色底 | rounded_box 贴士框 + icon | 新 painter（简单几何） |
| 8 | 场景页 | 整页 70% 全幅场景 + 底部 30% 文字横条 | 1 张 full 0.70 | 横条内 accent_bar 标题 + paragraph | 无 | ref 改比例+贴边 |
| 9 | 结尾页·金句型 | 整页主题色深底（非近黑）+ 中央大字金句 | 0 张（纯排版页） | center 金句大字（文案首句）+ 下方小字说明段 | 主题色小装饰（圆点/短横） | 新 painter（居中排版，简单） |
| 10 | 结尾页·总结型 | 上 50% 温暖收尾图 + 下部总结文字区 | 1 张 full 0.50 | accent_bar 总结标题 + paragraph（含行动建议） | 角落圆角贴纸（2-4 字要点词） | ref+sticker 组合 |

新增 painter 清单（本次要写的绘制函数，全部几何级）：
`highlight`（荧光块：文字区局部底色矩形，-pad 内缩）、`banner_strip`（横幅条）、
`rounded_box`（贴士框）、`icon`（已有 _icon_char 复用）、`sticker`（圆角块+短词）、
`polaroid`/`tape`（白边框/半透明矩形角贴，grid 单元级）、`center_quote`（居中大字排版）。
现有可复用：_draw_title(竖条/居中)、_draw_capsule、_render_points_col、_draw_dashes、
_paste_cover(圆角裁切)、_paste_grid+_grid_captions、vs 徽章、渐变 scrim。

## 5. 参考图自动扩充管线（用户核心诉求）

```
用户丢参考图（聊天/管理页上传）
  → VL 布局分析（专用提示词，输出受限 JSON：照片区数量/几何占比/排布、
    文字区位置与标题形式、装饰元素→painter 词汇表映射、配色基调、页角色判断）
  → spec 草稿生成（映射到 v1 schema；识别不了的装饰→nearest painter 或丢弃并备注）
  → 合法性校验（§3 规则；photo_zones 占比 0.45-0.75、字号档、深底约束）
  → 预览渲染（拿 1 组样例文案+样例插画按 spec 渲 1 张 PNG）
  → 入库 source=vl_extracted, enabled=false（管理页/聊天里人工点启用）
```

- VL 提示词与 11 预置模板的 spec 作为 few-shot 样例（识别锚点：「这像哪种已知页型+哪里不同」）；
- 一次可给多张图（批量提取，每图一模板草稿）；
- 早期（管线未建好前）：用户在对话里丢图，我按同一套流程手工提取入库——先跑通体验，P3 再自动化。

## 6. 模板库管理

- **DB**：`compose_templates` 表（迁移 028）：id/name/spec(jsonb)/page_role/tags/source/
  enabled/version/preview_asset_id/created_by/created_at；幂等种子=11 预置模板；
- **API**：GET 列表（过滤 role/source/enabled）/ POST 新建 / PATCH 改名改 spec 改启停 /
  POST /preview（传 spec+样例内容渲 PNG）/ POST /extract（传图片 URL→spec 草稿）；
- **管理页**：Admin.js 加「版式模板」tab——卡片列表（预览图+名称+来源徽标+启停开关），
  JSON 编辑器（带校验），「从参考图提取」上传入口；
- **纪律**（沿用风格库 SSOT 教训）：预置模板以仓库 `data/compose_templates.json` 为单一事实源，
  管理页改预置模板=改仓库文件（sync 脚本幂等同步），提取/手工模板归个人库。

## 7. 与管线的接法

- `pick_layout` → `template_select(task_id, 题材标签, 页角色轮换)`：轮换规则沿用
  5 页=(cover, content-场景, content-拼贴, content-特写, ending-总结) 的页角色序列，
  在同角色 enabled 模板内按 task_id+页序轮换挑具体模板（同角色多模板=版式多样性来源）；
- 渲染输入不变：PageSpec（title/section_title/paragraph）+ 无文字插画（sub_prompts 机制，
  photo_zones>1 时按 zone 数量生成多张）+ 主题色板；
- 质检链不变：compose 模式文字项（text_ok）必然通过（程序压字），主体/水印/跨页检查照跑。

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| 程序版式仍显模板感 | 同页角色多模板轮换+装饰微随机（贴纸位置/虚线长度 seeded by task）；预期管理：到参考标准七八成为目标 |
| VL 提取 spec 不合法/难看 | 封闭词汇表+校验+预览渲染人工启用，坏模板不进生产 |
| 双链维护成本 | compose 渲染器独立模块，直出链零改动；两链共用 PageSpec/插画生成/质检 |
| 深底页超标（手册：主风格一致） | 轮换器保证深底金句型全套≤1 页（沿用现约束） |
| 手册红线（模板感/美观度扣分项） | P4 试运行对照验收标准人工快审，不过关不切默认 |
