# 案例风格库与生图关键字重设计（2026-09-23）

> 依据：0922测试题 30 题链接全集 150 张案例图，直接目视 23 张（覆盖全部题材类别）+
> 同题交叉验证。用户裁决：弃用当前"程序排版"呆板图文方式，按案例风格库重设计生图关键字。

## 1. 案例风格库（30 题共性提炼）

### 1.1 整卡骨架（几乎全部 150 张一致）
- 3:4 竖卡；**上部 55-62% 一张真实生活摄影感大图**，下部 38-45% **主题色浅调底文字区**
- 照片↔文字区：直切或照片下缘微圆角；封面页照片上常压一行大字结论
- 文字区三段式：**标题**（黑粗体 + 主题色装饰：圆点/竖条/荧光高亮笔，非几何方块）→
  **小节标题**（序号圆点或 emoji + 黑粗）→ **段落正文**（深灰，行距舒适）
- 点缀：手绘感小图标、圆角贴纸、虚线分隔——**柔**，非程序几何

### 1.3 摄影感关键字（与我们 AI 插画的最大差距所在）
案例照片全部是**真实生活摄影**质感，非 AI 渲染插画：
- 真实手机摄影/生活实拍质感，自然窗光或暖白室内光
- **浅景深背景虚化**、真实材质细节（织物纹理/食物光泽/宠物毛发/水珠）
- 生活场景：家居桌面、厨房台面、卧室床品、户外草地——不摆拍、不棚拍
- 暖调白平衡、干净构图、主体突出、竖幅
- 我们此前插画：平滑渐变假背景、渲染感材质 → "呆板"主因之一

### 1.4 文字处理（案例 vs 我们程序版式）
- 案例：标题装饰是圆点/短竖条/荧光笔高亮（有机感），小节用序号圆点/emoji，
  段落自然行文，色底是**主题色浅调**（每题不同）
- 我们 ref 版式：固定浅米底 + 方正橙竖条 + 方块序号徽章（几何、机械、全部题一个样）→ "呆板"主因之二

## 2. 新生图关键字体系（整卡直出，弃用程序排版）

**链路切换**：`IMAGE_COMPOSE_MODE=false`（混合链保留作回退）→ 走模型直出
（get_image_prompt 组装），页文案 = 段落式 specs 的 rendered（标题+小节+段落，
0922 分页链已就绪）。VL 综合质检（逐字+字形+主体+协调+水印）逐页兜底重生。

### 2.1 新中文底座（shared_style.txt 重写为案例骨架）
核心句式（见落地文件）：
- 竖版3:4图文卡；上部约六成真实生活摄影感大图（自然光/浅景深/真实材质/生活场景/竖幅），
  下部约四成主题色浅调底文字区
- 标题黑色粗体+主题色装饰（圆点/短竖条/荧光高亮笔之一）；小节标题序号圆点+黑粗；
  正文深灰段落；留白充足
- 保留全部汉字铁律（逐字渲染/规范简体/禁变形阴影描边透视/字号≥7%/跨页双维度去重/禁带文字物件）
- 主题色由分页 spec 的 theme 字段注入（题材→色系映射表进 page_schema）

### 2.2 版式角色（layouts_cn.txt 重写）
- 封面页：照片压一行大字结论 + 下部标题+结论段
- 内容页：骨架标准型（上图下文+小节序号递进）
- 结尾页：同骨架 + 总结段 +（可选）贴士贴纸

### 2.3 摄影感关键字（插图/照片区专用后缀，进 hard rule 尾段）
「真实生活摄影质感，手机实拍感，自然窗光，浅景深虚化，真实材质细节，
生活场景不摆拍，暖调白平衡，干净构图竖幅」

## 3. 风险与兜底
- 整卡直出的中文段落（80-100字/页）伪汉字风险：VL 综合质检逐字校验 + 不合格重生 1 次 +
  RejectMark 人工兜底（链路现成）；基准批实测该链有效
- 程序排版链（compose/ref）保留为回退开关，不删除
