# 生图学习：借鉴图片「丰富度」训练（2026-08-24）

## 一、素材与抓取

- 素材：用户提供的 xlsx 中 **37 个新榜编辑器链接**（d.newrank.cn/nreditor/preview?noteId=xxx），
  每篇 4 页图卡，共 **148 张图**，题材覆盖生活科普/数码/历史人文/政务办事/宠物/财经/职场等。
- 抓取方式（关键发现）：预览页是 React 空壳，但数据接口**免登录直连**——
  `POST https://gw.newrank.cn/api/helper-client/xhsEdit/getXhsNote`，
  body `{"uuid": noteId}`，头 `n-token: 342bdbf6864146f59730fbd6eace18f9`。
  之前以为要登录 cookie 是误判（用编造 noteId 测试才返回 data:null）。
  `imgs` 字段 JSON 内每项 `response` 即图片 CDN 直链（火山 TOS）。
- 原始数据：`借览分析/notes.json`（37 条 title/body/imgs）、`img/`（148 张原图）、
  `sheets/`（37 张 2x2 对比拼图）。

## 二、借鉴库的「丰富度公式」（37 篇全部遵循）

**封面公式**：特大粗黑体两三行标题（单行占版宽约 80%、占上部 35-40%）+ 1-2 个强调色
关键词（荧光底块或彩色字）+ 40-75 字导语（两条圆点要点）+ 一张实景/产品照片。

**内页公式（核心差距所在）**：
1. **双色强调大标题**（我们已有）；
2. **标题下一条主题深色横幅细条，白字一句金句副题**——37 篇每篇每页标配，
   一句利落判断句（"天气原因改签通常免费""一个管做什么，一个管怎么做"），
   我们完全没有；
3. **圆形数字序号章**（强调色圆底白字 ①②③）引导要点——几乎每页；
4. **2-3 张圆角信息卡**（图标+加粗小标题+1-2 行说明，单卡 ≤40 字）；
5. **右下竖构图实景照片贯穿内页**（圆角相框/撕纸边框，形成栏目感）；
6. **照片角部圆形结论贴纸**（"能吃！""注意！""避坑"）——约 1/4 篇目，记忆点极强；
7. **关键词荧光高亮底块**（强调色浅调底+深字，像荧光笔划过）——每页多个。

**尾页公式**：结论式标题（"一张说清/按这个顺序"）+ 编号步骤卡/绿√红×两栏速查对比
+ 底部深色结论横幅收一句口号；个别篇目加"虚线填写框"互动元素。

**信息密度**：封面 40-75 字；内页 80-180 字，主流 90-130；单卡 ≤40 字。
我们此前骨架目标 50-70 字，偏薄。

**色彩体系**：浅底（米白/浅灰白/淡蓝灰）+ 深色主文（深藏青/深墨绿/深褐）+
**单一强调色与题材绑定**（橙=生活、蓝=数码、红=维权/危险、朱红=历史、金=财经）；
警示/转折页整页切换强调色而底色不动。历史人文篇独有"做旧宣纸+黑白老照片+朱红印章"皮肤。

## 四、训练落地（五处，双保险）

1. **中文底座 `_SHARED_IMAGE_STYLE`**：主题深色横幅细条/荧光高亮底块升为推荐形式
   （与胶囊标签并列"不算深色框"）；近黑大块文字底仍限全套 6 页最多 1 次（防负优化不变）。
2. **英文底座 `_IMAGE_CONSTRAINTS_EN`**：同步三种 device（CAPSULE labels / banner bar /
   highlighter blocks），横幅句子必须逐字取自本页文案（不破逐字渲染铁律）。
3. **六页布局 `_PAGE_LAYOUTS`（中/英）**：页角色化注入——封面标题加大至近八成版宽、
   要点页序号章+横幅条、特写页相框+结论贴纸、清单页荧光底块、总结页绿√红×速查或口号横幅。
4. **扩写器 `visual_writer._VISUAL_PROMPT`**：新增 RICHNESS DEVICES 段——每页至少织入
   一种 device、同一 device 全套不超 3 页、禁止堆砌；style_en 须声明横幅底色与贴纸样式。
5. **分页 `PAGES_PROMPT`**：骨架目标 50-70 → **60-85 字**（仍守 30-100 铁律与 25 字均衡），
   第 2-5 页首句要求写成利落判断句（供横幅条使用）。

**风格库（迁移 019）**：新增 2 条公共风格，补齐题材空白——
- `新中式史料卡`（历史/朝代/诗词/条约/典故…）：做旧宣纸底+深褐书法字+朱红印章数字强调+黑白老照片撕纸相框；
- `政务办事指南卡`（办事/证件/社保/申领/维权…）：浅蓝灰底+藏青标题+红色只给硬条件+序号章步骤卡+虚线箭头+尾页速查对比。

**记忆会话**：`scripts/seed_richness_memory.py` 把上述基准一次性写入
qvp-visual-memory-v1 会话（本地+服务器各执行一次），与代码注入互为双保险。

## 五、防负优化红线（未动项）

- 3:4 尺寸铁律、六页风格快照统一、逐字渲染/HANZI RULE、主体锚定与视觉审核口径——全部不动；
- 近黑深底文字框全套最多 1 次的约束保留（横幅条用饱和主题深色，与近黑框明确区分）；
- 30-100 字硬界与 25 字均衡校验保留，只上调骨架目标；
- 每页 device 至多 1-2 种、同 device ≤3 页，避免退化成新模板刷屏。

## 六、观察指标

上线后重点看：①审图驳回率是否下降；②横幅条/序号章是否稳定出现（抽检六页图）；
③30-100 字均衡校验通过率是否受 60-85 目标影响；④历史/政务类 query 是否命中新风格。
