# 发版记录 v15 · 2026-09-14

## 核心变更

生图主模型从 `gpt-image-2` 切换为 `gpt-image-2.5-flare`。

- 依据 [FusionAI 开放平台文档](https://www.fusionaix.cn/openapi/docs)，GPT Image 2.5 系列提供两个型号：
  - `gpt-image-2.5-flare`（默认主模型）
  - `gpt-image-2.5-sunburst`（备用型号，同 API 同参数）
- API 端点、请求字段与 `gpt-image-2` 完全一致：
  - `POST /v1/images/generations`
  - `POST /v1/images/edits`
  - 字段：`model`、`prompt`、`n`、`size`、`quality`、`resolution`、`output_format`、`response_format`
- 因此本次切换为**纯模型名替换**，无需改动请求体构造逻辑。

## 部署注意

1. **应用 `.env`**：确保服务器 `.env` 中 `IMAGE_MODEL=gpt-image-2.5-flare`（或按需设为 `gpt-image-2.5-sunburst`）。
2. **执行迁移 025**：容器启动时 `init_db.py` 会自动幂等应用；如需手动执行：
   ```bash
   psql -U qvp -d qvp -f migrations/025_gpt_image_25_rates.sql
   ```
3. **费率校准**：当前 2.5 系列费率暂按 `gpt-image-2` 的 ¥0.2/张 参照填入，待 FusionAI 账单实证后在管理页 `/api/admin/rates` 校准。
4. **回退**：如 2.5 在线路中出现兼容性问题，只需改回 `.env` 中 `IMAGE_MODEL=gpt-image-2` 并重启；历史 `gpt-image-2` 费率行仍在。

## 验证

- 本地单元测试：`tests/unit/test_channel_billing.py`、`tests/unit/test_image_gen.py` 通过。
- 真实出图验证需临时关闭 `MOCK_IMAGE_GEN=true`，并确认 FusionAI 账号余额与模型白名单已开通 2.5。

## v15.1 追加（2026-09-15）

**文字准确性优先 + Sunburst 单次精修兜底**

- 生图硬约束底座（`skills/image-prompt/shared_style.txt` / `constraints_en.txt`）追加：
  > If visual beauty conflicts with Chinese character accuracy, sacrifice visual beauty and preserve the exact Chinese characters.
- `src/gateway/image_gen.py` 的 `generate_image()` 新增 `model` / `channel` 覆盖参数，允许调用方强制指定模型与通道。
- OCR 判定文字错误后的重生路径改为**只修一次**、且固定用 `gpt-image-2.5-sunburst` + `fusion` 通道精修：
  - `src/pipeline/agent_shared.py::_garble_check_and_regen`（MCP/Agent 路径 garble 重生）
  - `src/pipeline/ai_review.py::_gen_one_with_review`（直连路径 AI 审核重生第二轮）
- 目的：避免文字错误时多次无意义换构图烧钱，把预算集中在一次更高精度的 Sunburst 精修上。
