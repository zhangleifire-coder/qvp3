# 2026年9月最终版 · 高质量文字生成与生图通用 Prompt 模板

> 版本：v1.0（2026-09-22）
> 来源：合并 7~8 月版与 9 月版提示词优点，对齐《笔记二创供应商生产标准手册 V2.0》验收口径，并吸收本仓库
> `skills/image-prompt`（直出底座）、`skills/visual-writer`（英文扩写）、`skills/page-subject`（主体锚定）、
> `src/services/poster_compose.py`（程序化文字 + 无文字插图混合链路）的实战条款。
> 适用场景：**3:4 竖版连续多页中文信息图**（小红书式图文卡），页数 5~6 页可调。
> 三种用法：**A 分页文案生成**（LLM 产文字）→ **B 整图直出**（生图模型连文字一起渲染）或
> **C 程序化文字入图**（程序排文字 + 生图模型只出无文字画面）。A 是 B/C 的上游，B 与 C 二选一。

---

## 0. 总纲：优先级声明（所有场景的第一段）

任何场景下，把下面这段放在 prompt 最前面，作为压倒一切的排序：

```
【优先级总纲（高于本提示词其余一切条款）】
文字准确性与可读性 > 主体正确与完整 > 跨页信息与视觉不重复 > 信息密度适中 > 视觉统一 > 装饰美感。
任何两条冲突时，牺牲后者、保全前者。视觉美感与汉字准确性冲突时，必须牺牲视觉美感。
```

为什么放最前：生图模型对约束的执行近似「注意力加权」，把优先级说成显式排序，比反复强调"文字很重要"更能压住模型自由发挥的冲动。

## 1. 全局铁律（三场景共用底座，编号引用）

以下 8 条是跨场景硬约束。后面各场景模板中以 `〔铁律N〕` 引用，不要删减；确需裁剪见附录三。

### 铁律1 · 汉字规范（P0，最高）

```
所有图上文字必须使用标准现代中文黑体字形（微软雅黑式无衬线体）。严禁艺术字、变形字、
异体字、书法字、手写字；严禁日文新字体（実・対・変・単・図・芸）、繁体字、自造字、乱码字符。
图中每一个汉字都必须是中国大陆规范简体字形。把图中文字当作需要逐字精确复制的排版内容，
而非装饰纹理：给定文案一字不差，不增字、不漏字、不改写、不翻译。
拿不准如何正确书写的字，宁可整词不出现，也绝不写错。
```

### 铁律2 · 文字渲染禁令（P0）

```
禁止：文字阴影、描边、发光、透视、倾斜、立体效果、艺术化变形；禁止字号过小
（最小字号字高不低于画面宽度的 7%）；标题/小标题/正文三级字号各自统一，
标题字号约为正文 2.5 倍；正文统一基线对齐；印刷级清晰度，边缘锐利无模糊。
```

### 铁律3 · 主体锚定与一一对应（P0）

```
每页画面主体必须直接描绘该页文案所讲的事物本身：标题（小标题）与图片一一对应，
小标题不得改写。风格描述词只作用于光影、色调与氛围，严禁把风格词具象化为
植物、发芽、石缝等隐喻物替换真实主体；禁止用符号、图腾、抽象造型代替具体事物。
主体清晰不被遮挡、不裁剪关键特征（完整出现，不截半）。
```

### 铁律4 · 跨页双维度去重（硬性规则）

```
整套 {N} 页必须形成连续的信息叙事：每页只承担一个核心信息任务，页面之间分工明确、
递进不重叠。
- 信息去重：前一页已经表达过的知识点、结论、动作、步骤、风险提示，后续页面不得再次
  作为主要信息点重复表达（补充新角度的新信息除外）。
- 视觉去重：前一页已经作为主视觉使用的场景、构图、道具、装饰元素、视觉隐喻，后续页面
  不得再次作为主要表达元素使用（同一主体在不同景别/角度的必要延续除外）。
```

> 这是 7~8 月版（视觉去重）与 9 月版（信息去重）的合并升级：两个维度都写成硬规则，缺一不可。

### 铁律5 · 信息密度适中

```
图片的信息度不要太少也不要特别多，适中就好：每页围绕一个核心信息点展开，
中等信息密度 + 明确视觉层级（标题区/正文区/强调区分工）+ 充足留白
（主色背景至少占画面三成，画面有呼吸感）。忌两个极端——极简到空、丰富到堆满。
整套图信息点合计 ≥5 个，覆盖多角度（是什么/为什么/怎么做/注意什么/结论），
用户只看图即可获取核心信息（图有独立信息量），图与正文互补而非重复。
```

> 最后一句对齐验收手册「图独立信息量」「图文互补性」两项 3 分标准。

### 铁律6 · 视觉统一（定义 + 继承双段式）

```
首页定义视觉基准：{style_desc}（含坚韧治愈风/高清这类气质词与「简约不简单、极简而高级」
的整体观感），并明确背景主色、标题强调色、标签色，主色 ≤3 种、冷暖协调。
第 2 页起全部继承：风格、色板、字体系统、光影质感与封面保持一致（主风格占整套 ≥80%），
只换场景与版式，不换视觉系统。整套所有图 3:4 竖版同尺寸（宽高比差异 ≤5%）。
```

> 合并逻辑：7~8 月版「定义一种视觉风格」负责首页，9 月版「风格与封面保持一致」负责后续页。连续生成时首图即视觉锚点。

### 铁律7 · 禁带文字的物件

```
画面中不得出现自带文字的物体：包装袋/瓶罐标签、说明书、书名、毛巾 Logo、浴室标牌、
药盒文字、屏幕界面文字、路牌店招等。装饰元素一律无文字。不出现人脸（素人出镜是验收
红线）；不出现书籍。这些"非主要文字"是乱码与伪汉字的最大来源。
```

### 铁律8 · 排版多样与红线

```
排版不模板化：每页版式不同（见场景内版式轮换表），全套最多 1 页使用大面积深色底压字，
正文默认深灰/黑字直接排在浅色留白区（不要底色框、不要深色衬底）；底色与边框禁纯白纯黑，
必须用带色相的颜色。禁止出现「封面/第X页」等页样字样；无水印、无二维码、无引流信息、
无促销字样（硬广红线）；隐私信息（门牌、病历、账号）一律不出现。
```

## 2. 场景 A：分页文案生成 Prompt（LLM 产文字，B/C 的上游）

用途：把一份原始内容拆解成 N 页结构化图上文案。产出直接喂给场景 B 或 C。

```
你是小红书式竖版图文卡（3:4，共 {N} 页）的内容主编。把下面的原始内容拆解成 {N} 页图上文案，
每页一个 JSON 对象，输出严格 JSON 数组，无任何解释与 markdown 围栏。

拆解规则：
1. 页面分工（信息叙事链，页间不重复）：封面页给完整核心结论；其余每页从原始内容中承担
   一个独立信息任务（如：能不能做 → 什么时候不要做 → 具体怎么做 → 做完观察什么 → 结论），
   后页不得重复前页已表达的知识点。
2. 小标题从原始内容中原文摘取，不得改写；标题与该页画面内容一一对应。
3. 每页字段：{"title": "≤18字短句标题", "subtitle": "6-28字胶囊副题（可空）",
   "points": ["≤18字要点", "…最多4条"], "subject": "≤20字具体可画名词短语（该页画什么）"}。
4. 每页图上文字总量 80-130 字，任意两页相差不超过 40 字；要点句间内容不粘连、不重复。
5. subject 必须是具体可画的事物（如「加冰块的高脚杯牛奶」），禁止抽象词（「温馨」「成长」），
   禁止与文案无关的象征隐喻；文案讲什么就画什么。
6. 语气自然口语化，无 AI 机械感、无营销号口吻；数据与事实保持原文，不编造。

原始内容：
{raw_content}
```

> `subject` 字段即主体锚定的前置化：把「这页画什么」在文字阶段就定死，生图阶段只执行不发挥。
> 对应仓库实现：`skills/page-subject`（主体提取）+ `poster_compose.split_title_points`（标题/副题/要点拆分）。

## 3. 场景 B：整图直出生图 Prompt（API 生图，文字由生图模型渲染）

用途：一次调用生成整张图文卡（文字 + 画面都在图里）。信息密度高、版式控制全靠 prompt 时使用。
结构 = 总纲 + 底座（中文）+ 版式轮换 + 页文案；英文模型可加 `constraints_en` 译版（见 §3.3）。

### 3.1 中文底座（逐页拼装：底座 + 本页版式 + 本页文案）

```
【优先级总纲】（§0 原文）

〔铁律1~8 全文引用〕

竖版 3:4 图文卡片，本页是第 {i}/{N} 页。整体观感：{style_desc}——自然、真实、舒适、克制，
像杂志内页而非模板拼贴。本页版式：{layout_i}。

主标题用双色排版：主体字深色，其中 1-2 个关键词用强调色（{accent}，与整体配色和主题协调）；
对比类标题的「VS」等对比词也用强调色。正文直接排在浅色留白区，不要底色框。
三类主题色标注是推荐形式、不算深色框：①彩色胶囊/圆角标签压白字；②标题下主题深色横幅细条
（墨绿/藏青/深褐等饱和深色、非近黑，白字一句副题短句，句子取自本页给定文案，条高约为标题
一半）；③关键词荧光高亮底块（强调色浅调底配深字）。全套 {N} 页中近黑/深灰大块文字底最多
出现 1 页。

本页文案（逐字精确渲染，一字不差）：
{page_body}

本页画面主体：{subject}（直接画出该事物本身）。
```

### 3.2 版式轮换表（按页角色取用，每页不同；{N}=6 全用，{N}=5 去掉清单页）

| 页角色 | 版式指令（拼入 {layout_i}） |
|---|---|
| 封面页 | 主视觉大图占画面约三分之二，大标题置顶部加大加粗（单行可占版面宽度近八成），副标题只一行，留白充足 |
| 要点页 | 上文下图，正文拆 2-3 短句要点纵向排列，每条配主题强调色圆形数字序号章（圆底白字），要点间细线或小色块分隔 |
| 特写页 | 主体特写充满画面，圆角相框或撕纸边框，照片一角主题色圆形贴纸（白字 2-4 字结论词），文字放底部约四分之一主色横条内 |
| 清单页 | 圆角卡片式分栏 2-4 块，每块一个小标题、块间明显间距，关键词荧光高亮底块标注 |
| 场景页 | 全幅场景图铺满画面，文字置于顶部留白区，图文以弧线或斜线自然衔接 |
| 总结页 | 居中大字结论 + 最多两行小字；或左右两栏速查对比（推荐项主题绿对勾、避免项砖红叉号），视觉收尾干净 |

### 3.3 英文骨架（喂 gpt-image 系模型时，底座换译版 + visual_writer 扩写）

两步链路（本仓库已验证）：

1. **视觉扩写**（`skills/visual-writer`）：中文页文案 → 每页 40-80 词英文视觉方向（主体/环境道具/
   光影方向与质感/机位构图/色彩情绪 + 富信息装置），同套统一 style_en（背景 tint + 标题强调色 +
   标签色 + 一句选题关联理由）。扩写只描述画面，**不扩写文字内容**。
2. **硬约束英文底座**（`skills/image-prompt/constraints_en.txt`）：铁律 1~8 的英文版（HANZI RULE
   独立成段：simplified mainland forms / never shinjitai 実対変単図芸 / verbatim typeset copy /
   sacrifice beauty for accuracy）+ 扩写产物拼装后调生图 API。

富信息装置（防页面单薄，每页至少 1 种、同种不超过 3 页、不堆砌）：标题横幅细条（白字副题取自
本页文案）／圆形数字序号章／结论贴纸／圆角/撕纸相框／虚线箭头步骤链（教程页）／对勾叉号两栏
速查（总结页）。

## 4. 场景 C：程序化文字入图（混合链路，文字质量最稳）

用途：文字由程序（PIL/微软雅黑）排版渲染，生图模型只产出**无文字画面**，程序合成整卡。
消灭伪汉字的主链路（compose v6）。分两个子模板：

### C-1 · 无文字插图生成 Prompt（给生图模型，严禁出字）

```
{scene_description}（该页画面主体 {subject} + 场景/道具/光影/机位/色彩情绪描述，
已剥离全部版式与文字指令——凡含「竖版/横版/留白/标题/排版/图文卡片/卡片/分栏」的子句一律剔除）
；画面要求：{visual_brief}（风格库忌讳/描述/标杆规范中的纯画面条款，≤220 字）
，纯画面、无排版、无标题、无文字、无字母、无数字、无符号、无水印、无界面元素。
```

出图后接 VL 文字检查（宽松版：豁免 VS/箭头/刻度），检出文字则带同 prompt 重生一次，
仍不过由调用方决定占位或放弃（对应 `gen_textfree_illustration` 实现）。

### C-2 · 程序排版规范（代码侧执行标准，人工排版本时同此）

```
字体：微软雅黑 Regular/Bold（或思源黑体），全篇同一字体系统。
层级：标题 ≤18 字、字高≈正文 2.5 倍、加粗；副标题 6-28 字入彩色胶囊（白字）；
要点 ≤18 字/条、最多 4 条、条间细线或图标分隔；每行短句折行，不裁字。
配色：底色从风格库底色句解析（禁纯白纯黑）；浅底深字/深底浅字按底色亮度自动切换；
标题双色——主体字深色 + 1-2 关键词强调色；主色 ≤3 种。
留白：主色背景 ≥30%，边距统一，要素对齐（左右基线对齐）。
深底压字整套最多 1 页；禁「封面/第X页」字样；渲染分辨率 3:4，导出印刷级清晰度。
```

### C-3 · 链路分工原则（为什么要拆）

把「高信息量 + 多样构图 + 精准中文排版 + 无乱码 + 视觉统一」五项任务压给一次生图调用，
是目前 API 生图模型最常见的翻车原因。混合链路把它拆成：

| 任务 | 执行方 | 手段 |
|---|---|---|
| 文字内容与排版 | 程序 | 铁律 1/2 由代码 100% 保证（字体文件直渲染，不存在伪汉字） |
| 画面与构图 | 生图模型 | C-1 无文字 prompt，任务被简化为纯画面生成 |
| 跨页去重 | 场景 A + 编排 | 文字阶段信息去重 + 版式轮换 + 多图数量确定性随机（1-6 张） |
| 视觉统一 | 风格库 + 色板解析 | 同一 style_desc 驱动色板与 brief，主风格 ≥80% |

## 附录一 · 变量对照表

| 变量 | 含义 | 来源 |
|---|---|---|
| `{N}` | 总页数，5 或 6 | 业务配置（仓库现行 6 页；9 月实验版 5 页） |
| `{style_desc}` | 统一风格描述（气质词 + 底色 + 质感 + 装饰语言） | 风格库（server_styles.json / styles 表） |
| `{accent}` | 标题强调色（1-2 关键词用） | 风格库或 visual_writer 自选 |
| `{layout_i}` | 第 i 页版式指令 | §3.2 轮换表 |
| `{page_body}` | 第 i 页图上文案（逐字渲染） | 场景 A 产出 |
| `{subject}` | 该页画面主体（≤20 字可画名词短语） | 场景 A 产出 / page-subject 提取 |
| `{raw_content}` | 原始内容（取证素材/长文） | 上游 |
| `{scene_description}` | 纯画面描述（已剥离版式词） | visual_writer 扩写 / 文案方 |
| `{visual_brief}` | 风格库纯画面条款（≤220 字） | `visual_brief()` 抽离层 |

## 附录三 · 裁剪指南
