# 对齐参考样式改造方案（2026-09-22 · 用户提供 0922 测试题标准）

> 触发：用户裁决——「目前生成的 query 都不合格，0922测试题.xlsx 链接里的图片和文字才是正确的产出」。
> 样本：30 题（xlsx A 列 query + C 列新红编辑器预览链接），已抽查 2 题（幼犬出门/墨水洗渍）全量图文。

## 1. 参考产出规格（正确标准，两题一致）

| 维度 | 参考标准 | 我们当前产出 | 差距 |
|---|---|---|---|
| 页数 | **5 张卡** | 6 张 | 页数不同 |
| 版式 | **固定上图下文**：上部 55-60% 实景实拍风格图，下部 40% 浅米色底文字区 | 5 版式确定性轮换（overlay/top/left/right/vs）+ 宫格 1-6 张 | 版式语言不同 |
| 标题 | 黑字加粗大标题（≈正文 2-2.5 倍），左侧橙色竖条装饰 | 双色混排标题 + 胶囊副标题 | 样式不同 |
| 文字密度 | **每页一节整段正文**（emoji 序号小节标题 + 90-120 字完整段落，3-4 句实操内容） | 副题胶囊 + 4 条 ≤18 字短要点（~40 字） | **核心差距：段落 vs 短要点** |
| 插图 | 单张生活实拍感场景图（狗与主人/衣物污渍特写，无文字） | AI 无文字插画，宫格多张 | 数量与质感不同 |
| 正文 | 引言 + 一/二/三/四节 + 总结 + 免责（≈550 字，口吻真实具体） | 同构 ✓ | 基本一致 |
| 底色 | 浅米色系文字区 | 39 风格库轮换（含深色系） | 色彩策略不同 |

## 2. 改造点（v0.1.4 分支内继续，compose 链对齐）

### C1 分页 schema 段落化
`page_schema.PageSpec` 字段语义调整（结构兼容，不改表）：
- `points` → 渲染为段落时使用新字段 `section_title`（小节标题）+ `paragraph`（90-120 字整段）；
- render_page_text = title + section_title + paragraph；
- 分页提示词（page-split SKILL.md）改为 5 页 × 每页一节段落（封面页给结论段，中间页各一节，末页总结段）；
- 页数默认 `page_count` 6 → **5**。

### C2 compose 参考版式（新增 layout="ref"，设为默认）
- 上部 ~57%：单张插图全幅圆角；
- 下部 ~43% 浅米底文字区：橙色竖条 + 黑字标题 → emoji 序号 + 小节标题 → 段落正文（微软雅黑，像素折行，行距 1.5）；
- 底色固定浅米系（奶油米/米黄），黑字+橙点缀——extract_palette 仅用于点缀色；
- 页脚不放（参考无页脚）。

### C3 插图 prompt 生活实拍化
- 恒单张（禁宫格）；prompt 风格改为「生活实拍感、自然光、真实场景、无文字」；
- subject 锚定保留（P2 成果）。

### C4 兼容
- page_specs 旧结构（points）仍可渲染（退短要点版式）；文本直出链（B 链）不动；
- PAGE_COUNT 可配仍生效（默认值改 5）。

## 3. 不做的事
- 不改正文链路（结构已同构）；不动风格库（compose 参考版式不消费风格轮换，B 链仍用）；
- 不动三道人工关卡/质检链（跨页/文字质检对新版式同样适用）。
