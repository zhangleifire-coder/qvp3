# 审图操作说明：错字 / 糊字处理流程

> 适用版本：qvp3（本地 8005 / 服务器 8005，镜像 v20-20260918 及之后）
> 更新日期：2026-09-18
> 核心原则：**机器质检只拦"明显大错"，交付质量以人工审图为最终防线。**

---

## 一、背景：机器质检能做什么、不能做什么

| 检测层 | 能抓住 | 抓不住（需人工） |
|---|---|---|
| 双候选 + OCR 对撞选优 | 整页文字大面积错误 | 形似错字（OCR 自己也被骗） |
| VL 逐字校验（glyphverify） | 明显伪字、异体字、重度糊团 | 小字笔画粘连、单字轻微糊 |
| 渲染质量检查（rendererr） | 整段文字发虚 | 个别字糊、结构变形 |

**实证过的漏检案例**：「烘培/烘焙」（近形字）、「懂」字右半糊团、「皮」字结构粘连——机器全部放行，人工发现。

所以审图时必须**逐字放大核对**，不能只扫一眼。

---

## 二、三条处理路径（按问题数量选择）

### 路径 A：单张图「修改」定点重画 —— 个别错字/糊字首选

1. 左侧「任务审核」→ 待审队列选中任务。
2. 右侧「交付配图」区找到问题页 → 点该图下方 **「✎ 修改」**。
3. 弹窗中「修改意见」**写清楚哪个字有问题**，例如：
   - `正文第3行"懂"字糊成一团，重排时该字必须笔画清晰`
   - `"皮"字写错（中间粘连），按文案逐字重排`
   - 留空 = 仅换构图重生成（文字不动）。
4. 点 **「↻ 重新生产该图」** → 后台异步执行，**约 1 分钟**。
5. 稍后刷新页面看新图；**老图自动存历史**，点图可新旧对比。
6. 新图仍不满意可重复本流程；重试不限次数但每张都计费。

要点：修改意见越具体（哪个字、什么问题），重生合格率越高；意见会追加到原提示词后。

### 路径 B：「标问题」+ 驳回 —— 多页/多项问题批量重做

1. 问题页点 **「⚑ 标问题」**，逐项填写问题说明（**必填**，如"P3 配图『烤』字错字"）。
2. 分页文案和交付配图都可标；一页可同时标文案+图。
3. 底部「整体驳回原因」：有标记时选填，无标记时必填。
4. 点 **「驳回」** → 系统**自动定点重做所有标记项**，其余内容保留不重跑。
5. 提示"已驳回 N 项标记，已自动重做对应内容"即成功；进度在「任务中心」查看。
6. 重做完成后回到本页复核新图。

要点：只标确实有问题的项——未标记的内容不会被动，避免全链重跑烧钱。

### 路径 C：人工修图/外部生图替换 —— 重生多次仍不满意

1. 问题页点 **「⬇ 本页生图包」**：下载 zip，内含当前配图原图 + 该页全部分页文案/提示词。
2. 本地修图，或拿文案到外部生图工具生成满意的图。
3. 回到该页点 **「⬆ 人工图」** 上传替换。替换后该页标记为 `manual`（人工图），不再参与机器重生。

要点：适合"AI 怎么重生都不满意"的关键页（如首页产品图）。上传前确认图是竖版 3:4（1152×1536）。

## 三、字形质量检查 SOP（审核每张图时执行）

按顺序检查，每步都对整张图放大看：

1. **标题大字**（2 行内）：逐字认读，有无错字/多字/漏字。
2. **正文/标签小字**（最容易出错）：**逐字放大核对**，重点：
   - 复杂结构字：懂、餐、藏、赢、蘸、爆、镰
   - 高频近形字（历史出错位）：
     - 焙（火）≠ 培（土）——「烘焙」
     - 拨 ≠ 拔 ｜ 末 ≠ 未 ｜ 己 ≠ 已 ≠ 巳
     - 蓝 ≠ 篮 ｜ 度 ≠ 渡 ｜ 辩 ≠ 辨 ≠ 辫
3. **字体渲染质量**：每个字近看——
   - 笔画是否分明（「懂」类复杂字最容易糊成一团）
   - 有无粘连、断笔、缺笔、糊团
   - 小字的偏旁部首能否分辨
4. **图面文字范围**：图上应只有该页分页文案；若出现文案以外的标签/卖点/价格，属越界（可在修改意见中要求去除）。

发现任何一项 → 按第二节路径 A 或 B 处理。

## 四、机器质检留痕怎么看

机器校验过的页会在数据里留下标记（审图时看不到，复核/排查时有用）：

| 留痕 | 含义 |
|---|---|
| `glyphverify` | 该页过了 VL 逐字校验 |
| `lockerr` | 校验发现分页文案与图不一致（已触发重生） |
| `glypherr` | 校验发现错字/异体字（已触发重生） |
| `rendererr` | 校验发现文字渲染质量差（已触发重生） |

**含义**：带 `lockerr/glypherr/rendererr` 的页是机器认定有问题并重生过的——人工复核时这些页要重点看（机器判定也可能有误，重生结果未必更好）。

查询方式：任务详情接口返回的 `prompt_used` 字段，或数据库 `assets.prompt_used`。

## 六、常见问题

**Q：重生出来的图和原来一样糊？**
A：修改意见里加硬要求，如「每个字必须笔画分明、禁止粘连，文字优先级高于画面美观」。仍不满意走路径 C 人工替换。

**Q：一张图多处错字，要一个个改吗？**
A：不用。「标问题」一次驳回整页重做，修改意见里列出所有错字位置。

**Q：机器质检说通过了，我还需要逐字看吗？**
A：需要。机器只保证"没有大错"，「懂糊」「皮错」这类问题机器实测漏检率很高（见第一节）。

**Q：整批 6 张都不错，就是字体整体偏虚？**
A：这是生图模型的风格采样差异。可将该任务标记驳回（理由：整体文字发虚），重做时会换采样；或接受现状——画面风格与文字锐度存在一定取舍。
