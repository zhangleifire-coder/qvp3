# 系统结构分析（2026-09-24 现状）

> 范围：release/v0.1.4（HEAD bd1ad98，worktree code-v0.1.4/）
> 服务器：th@117.34.118.115 qvp3 容器（8005），运行态与代码默认差异见 §10

## 1. 总览

FastAPI 单体后端 + Vue 静态前端 + Postgres + openserp（自托管搜图/搜页），
Docker 单容器部署（`qvp3-app`），启动时 `init_db.py` 幂等应用全部迁移
（27 个 SQL）+ 同步风格库与版式模板种子。生产路径 = **staged Agent 管线
（4 节点）+ 混合合成出图链（模板库版式 + 程序压字 + 参考图图生图插画）**。

```
Query 导入 → [关卡1 文字核查] → [关卡2 实景审图*] → 生产管线 → [关卡3 审核] → 交付
              text_check        refs(对比/单品)      staged×compose        review
```

## 3. 生产管线（staged，agent_pipeline_variant 默认值）

```
node_agent_evidence（dsh 检索证据→evidence 表，可空）
  → node_agent_draft（draft-write 人设+概念保真/不收敛 → drafts；
      人工核定正文直通不烧 Agent）
  → node_agent_pages（page-split 段落式 5 页 → page_copies + tasks.page_specs）
  → node_agent_assets（出图，见 §4）→ 质检链（§5）→ reject_marks → review
```

断点语义：阶段间只经 DB 传数据，缺上阶段产物即报错（可断点续跑）。
feedback 驳回意见注入 draft/pages 提示词（regen 机制）。

## 4. 两条出图链（本日核心演进）

**混合合成链（服务器运行态默认 IMAGE_COMPOSE_MODE=true）**
```
template_select(task_id, 页序, 题材tag)          ← 模板库 DB（18 seed + 103 提取）
  规则：第1页cover；末页 content∪ending 池；中间 content；
       题材分优先+hash 打散+页序走位取模（同套不同版式）+同签名去重
  ↓
插画：ill_prompt（image_prompt_draft 优先——text-draft 起草，佩戴特写已开）
  + compose 后缀（创意构图段） → gen_textfree_illustration
  → generate_image(reference_image_urls=…)   ← refs 三来源：
       ①人工上传（refs/upload，文字核查阶段全模式可传，直落 confirmed）
       ②compare/single 实景审图关卡确认图
       ③general 自动搜（auto_refs→openserp，失败回退文生图）
  → fusion/moacode edits 图生图（失败链：另一通道→文生图，留痕日志）
  ↓
render_card(spec, PageSpec 内容, 插画, 色板)     ← compose_renderer
  封闭 painter 词汇表：标题(竖条/居中/图上压字/荧光高亮/居中金句)、
  小节(序号徽章/竖条/棕圆点)、正文(段落/条目/高亮条目)、贴士框、
  装饰(贴纸/横幅/虚线/VS徽章/拍立得/胶带/双圆环价格贴纸/手写斜标签/描边线)
  文字区底色(theme_light/warm_gray米灰/scrim/theme_deep)；
  垂直均衡双 pass（scratch 量高→下移）；条目模板遇段落文案自动降级
  ↓
VL 文字-Free 检查（不过重生一次）→ 成卡
```

**模型直出链（代码默认 IMAGE_COMPOSE_MODE=false，保留回退）**
shared_style（案例风格库关键字+佩戴特写+故事叙事链+繁简铁律）
+ layouts_cn 11 页型轮换 + _IMAGE_TEXT_HARD_RULE（29 对繁简混淆对）
→ gpt-image-2.5 整卡直出 → VL 综合质检（不合格 Sunburst 重生一次）。

## 5. 质检链（两链共用尾部）

| 检查 | 实现 | 失败动作 |
|---|---|---|
| VL 综合质检（每页4维） | visual_check.comprehensive_page_check：文字逐字+**繁简混淆专项**/主体/协调/水印 | 重生一次→仍不过 reject_marks |
| 跨页批量 | cross_page_check 拼版 VL：跨页信息重复/风格一致/深底页数 | reject_marks 人工 |
| 页间相似度 | page_overlap Jaccard 机检 | 同上 |
| 标题-Query 相关性 | text_check._QR_PROMPT：**概念偷换+概念收敛必查** | warn 非阻塞 |
| 正文规则 | 禁词/字数 400-700 | 人工核查提示 |
| compose 文字 | 程序压字，文字项结构性必然通过 | — |

reject_marks → review 关卡人工定夺（resolve/reject）。

## 6. 版式模板库（本日新建体系）

- 表 `compose_templates`（迁移 028）：18 预置 seed（SSOT=data/compose_templates.json，
  含 n03 杂志风族 6 个）+ 103 VL 提取模板（0922 案例 150 图聚类，popularity≥3 启用 10 个）
- 校验：validate_spec 封闭词汇表（排布/框/比例 0.45-0.75/元素流/装饰枚举，
  theme_deep 仅 ending）
- 提取管线：template_extract.analyze_layout（VL 选词量比例）→ analysis_to_spec
  确定性映射（非法值收敛、未知装饰丢弃）→ 校验 → 入库 enabled=false 人工启用
- 管理：/api/compose-templates CRUD+preview+extract；Admin 页模板库 tab
  （预览卡片+启停+参考图 URL 提取）

## 7. 人工关卡与数据模型

关卡：文字核查（awaiting_text，确认/重起草/编辑单页文案）、实景审图
（awaiting_refs，仅 compare/single，候选+手工上传+OCR 初筛）、审核（review）。

核心表：tasks（page_specs JSONB 快照/gen_style/text_review）、drafts、
page_copies、assets（交付图 official/generated + 参考图 confirmed candidate，
prompt_used 记 compose[模板id]）、compose_templates、reject_marks、
cross_checks、evidence/claims、batches、activity_logs。

## 8. 提示词资产（skills/ 16 包）与纪律

draft-write（人设+题面概念保真+概念不收敛）/ page-split（段落式+故事叙事链+
概念词保留+多形态分页）/ image-prompt（shared_style 案例库+layouts 11 页型）/
text-draft（核查三件套，佩戴特写已开）/ visual-writer / page-subject / polish…
纪律：改片段必跑 verify_skill_equivalence（有意变更→溯源 diff→重录基准）；
提示词库三级覆盖（用户自定义→admin DB→skills 默认）。

## 9. 前端与部署
