# 生图风格库训练方法总结

> 整理日期：2026-08-28。面向 8003 开发同事，分享我们在 8002 上落地验证过的「风格自适应 + 可训练风格库」完整方法。8003 已有 style_keywords 表和 Agent 风格判定，本文重点是从真实交付素材提炼风格模板的训练流程和使用闭环。

## 一、核心思路

生图提示词里**不要写死风格句**（如「坚韧治愈风、高清、极简高级」）。实测证明写死风格词有两个坑：

1. 所有题材千篇一律，用户会看腻；
2. 更严重的——抽象风格词会被模型具象化跑题。我们 A/B 对比实测：「坚韧」被 gpt-image-2 和 Gemini 双双画成「石缝发芽的植物」，和题目（冰牛奶做法）完全无关。

正确做法：**风格句做成可替换的变量**，从一个「风格名 → 匹配关键词 → 视觉描述词」的库里按题材自动选一种，整段描述词注入提示词，一篇图文的 6 页共用同一风格。

## 二、风格库数据结构

每条风格模板三个字段（对应 style_keywords 表）：

| 字段 | 作用 | 示例 |
|---|---|---|
| style_name | 风格名 | 米白扁平信息卡 |
| keywords | 题材匹配关键词（逗号分隔），用于按文章主题自动命中 | 教育,升学,学校,择校,政策,清单,攻略 |
| description | 视觉描述词，**整段注入生图提示词替换风格句** | 米白色背景低饱和扁平插画，墨绿/灰绿色系，黑色粗黑体大标题居上，圆形线性图标配圆角卡片清单…… |

支持 CSV 批量导入（列：style_name,keywords,description，同名覆盖幂等）。**注意 CSV 里含逗号的字段必须加引号**，否则会错列。

## 三、从真实交付素材提炼风格（关键步骤）

这是我们实际执行的流程，约 5900 张历史交付图（ChatGPT 生成、用户已验收）：

1. **按时间戳分组**：同一批生成时间的一组图 ≈ 同一篇图文的 6-10 页，保证样本覆盖不同「篇」而不是同一篇的很多页。
2. **均匀抽样**：每个日期目录均匀间隔抽 12-15 组，每组看 1-2 张（60 张左右即可覆盖主要风格，不用全看）。
3. **逐张记录四个维度**：题材、视觉风格（写实/扁平/3D/水彩）、主色调、构图排版特征（文字位置、留白、装饰元素）。
4. **聚类成「风格簇」**：把反复出现的版式归纳成簇，每簇产出：风格名、大概占比、一句话视觉描述词（要能直接当提示词用）、题材关键词。
5. **人工复核后入库**：先生成 CSV 留档，检查后再导入，导入后跑几个任务验证自动选择是否准确，不准就调 keywords。

我们提炼出的 8 条（附 CSV：`风格库_交付素材提炼.csv`）：

| 风格名 | 占比 | 适用题材 |
|---|---|---|
| 米白扁平信息卡 | ~40% | 教育/择校/政策/清单 |
| 杂志风产品对比卡 | 高 | 手机/家电/汽车等 3D 渲染 VS 对比 |
| 中轴双栏对比卡 | 中 | 学校/方案类扁平双色阵营对比 |
| 写实生活场景卡 | 中 | 美食/园艺/生活科普 |
| 航拍风光旅行卡 | 中 | 旅游/城市/路线 |
| 水彩绘本插画卡 | 中 | 规划/前景/人生选择 |
| 写实静物家居卡 | 低 | 家居/收纳/母婴 |
| 深色科技风 | 低 | 芯片/AI/电竞 |

## 四、风格选择优先级（两级库）

不同用户风格喜好不同，库分两级：

```
任务创建者的「默认风格」（用户手动钉选，直通，跳过 LLM 判定）
  → 创建者的个人风格库（非空则从中选）
    → admin 公共风格库（非空则从中选）
      → 代码内置风格库（兜底）
```

- 个人/公共库靠 `owner_id` 区分（NULL=公共），唯一约束做「同一 owner 内风格名唯一」（用两个部分唯一索引，NULL owner 之间也要唯一）。
- 选择方式：LLM 判定（把 query+正文摘要+候选风格清单给模型，输出风格名，**结果必须校验在候选清单内**）为主；LLM 失败或返回库外名字时，用 keywords 命中评分兜底（并列随机）。
- 选中后把风格名落到任务上（如 tasks.gen_image_style），前端展示，重生成时沿用，保证一篇 6 页风格统一。

## 五、使用闭环：越用越准

1. **存为我的风格**：任务详情显示本次选中的风格，一键把风格名+描述词存进个人库（补几个关键词即可）。
2. **偏好统计**：按用户聚合历史任务的 `gen_image_style`——任务数、审核通过率（通过/（通过+驳回））、重生成次数（被替换的配图历史版本数）。
3. **建议条**：某风格任务数 ≥3 且通过率 ≥80% 时提示「你似乎偏好 XX」，一键设为默认。
4. **设为默认**：钉选后该用户的任务直接用此风格，跳过 LLM 判定。

## 六、配套提示词经验（实测教训）

1. **主体锚定条款必须有**：风格词只作光影色调氛围，画面主体必须直接描绘本页文案讲的事物本身，严禁把风格词具象化成植物/发芽/石缝等隐喻物。没有这条，无参考图模式必跑题。
2. **排版层文字可信任，画面内嵌小字要规避**：标题/正文级中文直出基本零错字（gpt-image-2/Gemini 都是）；但产品屏幕、招牌、包装上的小字有 15-20% 乱码率，提示词里要写「尽量不出现带文字的物体」。
3. **分页版式要轮换**：6 页用同一版式会被模型画成模板复制。按页码轮换布局指令（封面上图下文、要点页上文下图、特写页底部横条文字区……），风格词不变只变布局。
4. **对比类要硬性约束**：每页必须同一画面同时呈现两个主体（左右分栏或上下对比），参考图顺序不能乱，否则模型会只画一个主体。
5. **同一篇内部风格统一、不同篇风格错开**：素材分析显示真实交付就是这规律——风格选择按「篇」做一次，6 页共用。

## 七、落地顺序建议（给 8003）

8003 已有全局 style_keywords + Agent 判定，建议按这个顺序补：

1. 把固定风格句从生图模板里抽出来变量化（如果还没做）；
2. 用本文第三节流程，从你们自己的交付素材提炼风格 CSV 导入（可直接用我们这份 8 条起步，再按你们题材调）；
3. 加 owner_id 做个人/公共两级库；
4. 加 gen_image_style 落库 + 通过率统计，形成偏好学习闭环；
5. 提示词补主体锚定条款（第六节第 1 条，这个收益最快）。

## 八、自然真实感优化（2026-08-24，836 张人工样例二次提炼）

**背景**：用户提供了两批人工用 ChatGPT Image 生成、且人工满意的样例（`8.21` 文件夹 334 张 + `8.13图片` 文件夹 502 张，共 836 张），要求生成图「更接近人工生成、更自然、更舒适真实」。抽样 4 张代表样本（产品对比卡×2、航拍风光卡×2）逐维度分析。

**四张样本的共同视觉特征（「人工感」的来源）**：

| 维度 | 样例共性 | 与旧提示词的差距 |
|---|---|---|
| 版式 | 图文区用**弧线/曲线自然分割**（扇形裁切、弧线+细金边过渡），对角 Z 字流线；忌生硬矩形拼贴 | 旧提示词无版式衔接要求 |
| 色调 | **低饱和莫兰迪暖调**：奶油米（#F2EAD9 级）、米金、香槟金、奶白、雾霾紫、陶土橘 | 旧的「背景不太白也不太暗」太模糊；「深色科技风」高对比深底在样例中不存在（样例里的手表对比也是奶油暖调） |
| 文字 | 大号粗黑体标题（约正文 2.5-4 倍）、层级分明、**深色字直接压浅色底**（无描边/阴影/色块）、每行短句、细线/刻度条分隔 | 旧的字号层级指引弱 |
| 质感 | **写实摄影 / 高精度产品渲染**：棚拍柔光、自然光带雾气、浅景深、地面轻微倒影 | 旧风格库含扁平插画/手绘倾向，与样例主体质感不符 |
| 装饰 | 极简克制、大量留白（浅色背景占 40-55%）、细线/小色条/细金边，无贴纸无花哨边框 | 旧的无留白比例指引 |
| 整体 | 「杂志内页」感：高级、克制、专业、舒适 | 旧的「坚韧治愈风」方向偏了 |

**本轮落地改动**（全部已同步：代码 + DB + CSV）：

1. `src/gateway/prompt_versions.py`：
   - `_SHARED_IMAGE_STYLE` 重写为分段结构（版式→曲线分割+四成留白、色调→低饱和莫兰迪暖调、质感→写实摄影/高精度渲染、文字→2.5 倍层级+深字压浅底、装饰→极简细线），保留汉字正确性/40 字上限/主体锚定等硬约束；删除「坚韧治愈风」「背景不太白也不太暗」。
   - `_PAGE_LAYOUTS` 六页轮换补曲线过渡与写实质感措辞，「全幅场景插画」改「全幅写实场景」（去掉插画引导）。
   - `IMAGE_PROMPTS["general"]` 前缀补「主体以写实摄影质感呈现」。
2. `src/services/combo.py` 内置 `IMAGE_STYLE_LIBRARY`：新增首选「自然写实暖调」（样例主体风格）与「实拍产品渲染」；其余条目往低饱和/自然光收敛。
3. DB `style_keywords` 8 条启用条目描述词更新（CSV 同步）：「深色科技风」更名「科技产品渲染卡」改浅色写实渲染；「杂志风产品对比卡」补地面倒影+细线刻度条；「航拍风光旅行卡」补弧形曲线分割+细金边过渡；其余补曲线衔接/低饱和措辞。

**使用建议**：后续人工验收新批次图时，若某风格出图被频繁驳回，优先调该风格 description 里的质感与色调词（往低饱和、写实、留白方向收），其次才动版式结构词。

### 8.1 第二轮扩样验证（2026-08-31，26 张分层抽样）

首轮只看了 4 张代表样本，方向正确但样本薄。第二轮按生成时间批次分层抽样（8.21 抽 13/49 批、8.13图片 抽 13/65 批，覆盖不同「篇」），累计分析 30 张。**修正与新增**：

| 修正点 | 首轮结论 | 第二轮数据（26 张） |
|---|---|---|
| 分割方式 | 「弧线/曲线分割」 | 水平**直线 + 暖棕细分隔线**才是主流（约 8 张），弧线只约 1/3——改为「水平暖棕细线或柔和弧线过渡」 |
| 标题字体 | 「大号加粗黑体」 | 题材分化：汽车/数码类粗黑体；**美食/生活/科普类 ≥8 张用衬线宋体**大标题（温润手作感） |
| 文字颜色 | 「深色文字」 | 明确为**深棕/深咖而非纯黑**，与米底同色系呼应（低对比柔和感的关键）；关键信息配**暖橘强调** |
| 装饰 | 「极简细线」 | 补充三类高频元素：**暖棕细分隔线、圆角卡片边框、要点前小圆图标**；旅游/美食手账类允许贴纸/胶带/标签点缀 |
| 低饱和 | 「严禁高饱和」 | 收窄为「**背景**严禁高饱和」——图片主体内部允许保留食材果蔬天然适度色彩 |

**30 张总统计**：奶油米低饱和暖底 30/30；写实摄影或高精度渲染 29/30（扁平插画 0 张、纯手绘 0 张）；深字压浅底 30/30；留白 4-6 成约 85%。题材分布：产品对比 8、美食配方 5、旅游手账 5、农业养殖科普 4、动植物科普 3、产品/农产品展示 3（对应风格库条目均已按题材证据更新：写实生活场景卡→衬线宋体+小圆图标+棚拍柔光；航拍风光旅行卡→手账贴纸点缀；杂志风产品对比卡→暖橘强调+尺寸细线标注+浅珊瑚橘弧形角饰）。

### 8.2 第三轮：风格分化与「按题材随机选向」机制（2026-08-31，再抽 20 张，累计 50 张）

第三轮每文件夹再抽 10 张（未看过的批次），**目标是找分化证据**。关键发现推翻/补充了前两轮：

1. **深色科技风确实存在**（8.21 三张：炭黑底+琥珀橙高亮+青蓝霓虹，用于性价比机/参数党）——第一轮曾把它并入浅色渲染卡，本轮恢复为独立条目。
2. **同一题材会走两种风格**：手机对比，家庭向（儿童手表）用奶油米写实渲染，参数党（千元机跑分）用深色科技风 → 印证「匹配后随机选向」的需求合理性。
3. **新风格方向**：手写暖心科普卡（奶油米+手写体标题+白圆角标签，宠物科普 ×2）。
4. **字体归风格管**：8.13 攻略/对比类标题全部粗黑体；衬线宋体是美食配方类专属；手写体是宠物科普专属——字体系统写入各风格 description，不进共享底座。
5. **多页统一手法**：同篇固定底色+字体+装饰语言，靠章节序号或栏目标签（定位丨影像丨健康丨选购）串联，封面页信息密度最低，全部无页码无水印。

**落地机制（直连路径风格自适应，`src/services/style_select.py`）**：

```
任务创建 → 生图节点首次执行时：
  gen_image_style_desc 快照命中？→ 直接沿用（重生成/定点修改同风格）
  否则 select_image_style(query)：
    ① 取启用风格库（DB 空 → 代码内置库兜底）
    ② query 与各条 keywords 子串命中计分
    ③ 加权随机（强相关更可能、弱相关仍有机会）；全不命中 → 全库等权随机
  → (风格名, 描述) 快照落库 tasks.gen_image_style / gen_image_style_desc
→ build_style_block() 生成风格段（含6页统一条款）注入全部6页提示词
   （nodes 首次生成 / regen 批量重生成 / edit_image 定点修改 三处同源）
```

- 共享底座 `_SHARED_IMAGE_STYLE` 同步瘦身为**风格无关硬约束**（版式结构/文字正确性/40字上限/主体锚定），色调/字体/质感全部下放到各风格描述词；
- `get_image_prompt(..., style_block=)`：风格段插在本页文案之后、硬约束之前；6 页同一段风格词、布局照常轮换；
- 库内现为 10 条启用（新增深色科技风、手写暖心科普卡），覆盖：教育清单/产品对比/双栏对比/生活摄影/航拍旅行/水彩绘本/静物家居/浅色科技渲染/深色科技/手写科普。
