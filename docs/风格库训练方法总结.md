# 生图风格库训练方法总结

> 整理日期：2026-08-28。面向 8003 开发同事，分享我们在 8002 上落地验证过的「风格自适应 + 可训练风格库」完整方法。8003 已有 style_keywords 表和 Agent 风格判定，本文重点是从真实交付素材提炼风格模板的训练流程和使用闭环。

## 一、核心思路

生图提示词里**不要写死风格句**（如「坚韧治愈风、高清、极简高级」）。实测证明写死风格词有两个坑：

1. 所有题材千篇一律，用户会看腻；
2. 更严重的——抽象风格词会被模型具象化跑题。我们 A/B 对比实测：「坚韧」被 gpt-image-2 和 Gemini 双双画成「石缝发芽的植物」，和题目（冰牛奶做法）完全无关。

正确做法：**风格句做成可替换的变量**，从一个「风格名 → 匹配关键词 → 视觉描述词」的库里按题材自动选一种，整段描述词注入提示词，一篇图文的 6 页共用同一风格。

## 二、风格库数据结构

每条风格模板三个字段（对应 style_keywords 表）：

| 字段 | 作用 | 示例 |
|---|---|---|
| style_name | 风格名 | 米白扁平信息卡 |
| keywords | 题材匹配关键词（逗号分隔），用于按文章主题自动命中 | 教育,升学,学校,择校,政策,清单,攻略 |
| description | 视觉描述词，**整段注入生图提示词替换风格句** | 米白色背景低饱和扁平插画，墨绿/灰绿色系，黑色粗黑体大标题居上，圆形线性图标配圆角卡片清单…… |

支持 CSV 批量导入（列：style_name,keywords,description，同名覆盖幂等）。**注意 CSV 里含逗号的字段必须加引号**，否则会错列。

## 三、从真实交付素材提炼风格（关键步骤）

这是我们实际执行的流程，约 5900 张历史交付图（ChatGPT 生成、用户已验收）：

1. **按时间戳分组**：同一批生成时间的一组图 ≈ 同一篇图文的 6-10 页，保证样本覆盖不同「篇」而不是同一篇的很多页。
2. **均匀抽样**：每个日期目录均匀间隔抽 12-15 组，每组看 1-2 张（60 张左右即可覆盖主要风格，不用全看）。
3. **逐张记录四个维度**：题材、视觉风格（写实/扁平/3D/水彩）、主色调、构图排版特征（文字位置、留白、装饰元素）。
4. **聚类成「风格簇」**：把反复出现的版式归纳成簇，每簇产出：风格名、大概占比、一句话视觉描述词（要能直接当提示词用）、题材关键词。
5. **人工复核后入库**：先生成 CSV 留档，检查后再导入，导入后跑几个任务验证自动选择是否准确，不准就调 keywords。

我们提炼出的 8 条（附 CSV：`风格库_交付素材提炼.csv`）：

| 风格名 | 占比 | 适用题材 |
|---|---|---|
| 米白扁平信息卡 | ~40% | 教育/择校/政策/清单 |
| 杂志风产品对比卡 | 高 | 手机/家电/汽车等 3D 渲染 VS 对比 |
| 中轴双栏对比卡 | 中 | 学校/方案类扁平双色阵营对比 |
| 写实生活场景卡 | 中 | 美食/园艺/生活科普 |
| 航拍风光旅行卡 | 中 | 旅游/城市/路线 |
| 水彩绘本插画卡 | 中 | 规划/前景/人生选择 |
| 写实静物家居卡 | 低 | 家居/收纳/母婴 |
| 深色科技风 | 低 | 芯片/AI/电竞 |

## 四、风格选择优先级（两级库）

不同用户风格喜好不同，库分两级：

```
任务创建者的「默认风格」（用户手动钉选，直通，跳过 LLM 判定）
  → 创建者的个人风格库（非空则从中选）
    → admin 公共风格库（非空则从中选）
      → 代码内置风格库（兜底）
```

- 个人/公共库靠 `owner_id` 区分（NULL=公共），唯一约束做「同一 owner 内风格名唯一」（用两个部分唯一索引，NULL owner 之间也要唯一）。
- 选择方式：LLM 判定（把 query+正文摘要+候选风格清单给模型，输出风格名，**结果必须校验在候选清单内**）为主；LLM 失败或返回库外名字时，用 keywords 命中评分兜底（并列随机）。
- 选中后把风格名落到任务上（如 tasks.gen_image_style），前端展示，重生成时沿用，保证一篇 6 页风格统一。

## 五、使用闭环：越用越准

1. **存为我的风格**：任务详情显示本次选中的风格，一键把风格名+描述词存进个人库（补几个关键词即可）。
2. **偏好统计**：按用户聚合历史任务的 `gen_image_style`——任务数、审核通过率（通过/（通过+驳回））、重生成次数（被替换的配图历史版本数）。
3. **建议条**：某风格任务数 ≥3 且通过率 ≥80% 时提示「你似乎偏好 XX」，一键设为默认。
4. **设为默认**：钉选后该用户的任务直接用此风格，跳过 LLM 判定。

## 六、配套提示词经验（实测教训）

1. **主体锚定条款必须有**：风格词只作光影色调氛围，画面主体必须直接描绘本页文案讲的事物本身，严禁把风格词具象化成植物/发芽/石缝等隐喻物。没有这条，无参考图模式必跑题。
2. **排版层文字可信任，画面内嵌小字要规避**：标题/正文级中文直出基本零错字（gpt-image-2/Gemini 都是）；但产品屏幕、招牌、包装上的小字有 15-20% 乱码率，提示词里要写「尽量不出现带文字的物体」。
3. **分页版式要轮换**：6 页用同一版式会被模型画成模板复制。按页码轮换布局指令（封面上图下文、要点页上文下图、特写页底部横条文字区……），风格词不变只变布局。
4. **对比类要硬性约束**：每页必须同一画面同时呈现两个主体（左右分栏或上下对比），参考图顺序不能乱，否则模型会只画一个主体。
5. **同一篇内部风格统一、不同篇风格错开**：素材分析显示真实交付就是这规律——风格选择按「篇」做一次，6 页共用。

## 七、落地顺序建议（给 8003）

8003 已有全局 style_keywords + Agent 判定，建议按这个顺序补：

1. 把固定风格句从生图模板里抽出来变量化（如果还没做）；
2. 用本文第三节流程，从你们自己的交付素材提炼风格 CSV 导入（可直接用我们这份 8 条起步，再按你们题材调）；
3. 加 owner_id 做个人/公共两级库；
4. 加 gen_image_style 落库 + 通过率统计，形成偏好学习闭环；
5. 提示词补主体锚定条款（第六节第 1 条，这个收益最快）。
